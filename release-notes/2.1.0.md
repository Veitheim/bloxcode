Installed copies update themselves on their next start. Restart Roblox Studio once afterwards so the 2.1 plugin loads.

## New

- **Remote map:** every RemoteEvent and RemoteFunction with the scripts that fire and listen to it, and warnings when the server uses client data without checking it, when nobody listens, or when a call is on the wrong side.
- **Templates:** leaderstats with saving, collectible coins, a shop GUI with server-checked purchases, obby checkpoints, kill bricks, a round system, day and night, sprint, a door with a prompt and Cmdr admin commands.
- **Tags & attributes:** every CollectionService tag and attribute with the objects that use them.
- **Selene linter** next to the type checker.
- **Color previews** for Color3 values with a color picker.
- **Ctrl+click on instance paths** selects the object in the Explorer and in Studio.
- New **changelog page** on the website: https://bloxcode-docs.seidl.workers.dev/changelog

## Claude

- New tools: `get_remote_map`, `get_tags_and_attributes`, `list_templates`, `insert_template`.
