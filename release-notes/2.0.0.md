The biggest Bloxcode update yet. Installed copies update themselves on their next start; new installs: **[Download for Windows](https://bloxcode-docs.seidl.workers.dev/download/windows)**.

After updating, restart Roblox Studio once so the new plugin loads (play tests, faster loading).

## New

- **Themes:** the new Bloxcode Night and Bloxcode Day, Dark+, Light+, Roblox Studio Dark, One Dark, Dracula, Monokai, GitHub Dark, Solarized Light and High Contrast, any accent color, and import of VS Code themes.
- **Settings page** (Ctrl+,): fonts, font size, line height, ligatures, minimap, word wrap, cursor and more.
- **Luau language server** (luau-lsp): type errors while you type, hover docs for the Roblox API, smarter autocomplete, Go to Definition (F12), Find References (Shift+F12) and Rename Symbol (F2) across scripts.
- **Output panel** (Ctrl+J) with prints, warnings and errors from Studio and play tests. Click an error to jump to the line.
- **Problems panel** and error counts in the Explorer and on tabs.
- **Search & Replace in all scripts** (Ctrl+Shift+F) with match case, whole word, regex and a path filter.
- **Command palette** (Ctrl+Shift+P).
- **Play tests from Bloxcode:** Play (F5), Run (F8) and Stop (Shift+F5).
- **Test mode:** Studio comes to the front and a small floating window shows Stop, errors and the Output while you play.
- **Script history** with a side-by-side diff and one-click restore.
- **Properties panel** for properties, attributes and tags.
- **Split editor** (Ctrl+\\).
- **GitHub:** create a repository and publish your scripts with one click (Rojo-compatible layout).
- **Discord Rich Presence** (optional, switched on with a small update right after 2.0).
- **Setup assistant** and a "What's new" window after updates.

## Claude

- 34 tools instead of 17: play tests with output, running Luau in Studio or inside a running test, undo and redo, type errors, whole GUIs in one step, search and replace across scripts, reading several scripts at once, your current selection, inserting assets, restoring versions and publishing to GitHub.
- **Review changes:** see Claude's script changes as a diff and accept or reject them.
- MCP resources and prompts (build a feature, fix errors, review code, secure remotes).
- Better instructions and a new starter prompt.

## Fixed

- Websites can no longer send commands to the local Bloxcode server.
- Claude's answers no longer get lost when Studio reloads the Explorer.
- When a script changes in Studio and in Bloxcode at the same time, you choose the version in a side-by-side view.
- Big places load much faster, with a progress bar, and Studio stays responsive.
